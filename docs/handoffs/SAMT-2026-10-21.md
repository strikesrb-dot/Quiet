## The grouping rules, as built (draft for step 5)

1. Group by the person's **stage**, not by feature type: not set up → ready → in a session → done. Each stage's
   screen shows only what works there.
2. **Lock only what can't work yet** (sessions before the voice is taught). Everything else (cards, the sign,
   reminders) works from the first open.
3. **Setup is the minimum, plus one proof it works** (the 10 s echo test). Optional training (other voices,
   phrases) comes later, from Settings, offered once at a natural moment (the first Conversation pick).
4. **One main action per screen**, in the dark capsule.
5. **A running task gets its own focused screen**: only the tools that help during it; numbers and corrections in a
   Details sheet; ending takes a deliberate 2-second hold (a test ends with a tap); the browser's Back can't leave it.
6. **Home is a launch pad**: the start card, at most three quick tools, then rows to the other places.
7. **Two places for everything else**: Progress (looking back) and Settings (changing how it works).
8. **Never deeper than Home → page → sheet.** Pages have Back and a large title.
9. **Settings is a short index grouped by thing** (Your voice · Sessions · Appearance · This device). Each row shows
   its value and opens its own sheet. No long scrolling list ("make sure settings isn't just a massive list").
10. **Measured, not eyeballed:** each page about one screen tall at 390 × 844; 0 px overflow at all five widths.

## How it's built (map)

- `src/template.html` (markup + Quiet Glass CSS, tokens copied from Repo-1), `src/ui.js` (views, router, sessions,
  sheets, progress, cards, reminders), `src/pipeline.js` (the Controller: verdicts, turns, talk limit, nudge, talking
  over someone, Talk freely), `src/mic.js` (audio engine and FakeMic), `voice-light.js`, `voice-neural.js`, `dsp.js`,
  `models.js`, `reminders.json`, `chooser.html`, `fonts/`, `extra/`. `python3 scripts/build.py` → `site/`.
- Views: home · session · progress · settings · phrases. `goView(v, 'push'|'replace'|'none')`; a session pushes its own
  history entry and the popstate guard keeps it on screen; leaving it steps back off that entry.
- Debug: `?fakemic=1&speed=N`; `SamtDebug.view()`, `.history()`, `.feed(name, url)`, `.trouble(kind)`, `.events`,
  `.ctrl`, `.engine.echoLog`.
- Storage: IndexedDB `samt` (`<mode>:profile|voice|phrases`, `shared:history`); localStorage `samt.<mode>.settings`,
  `samt.shared`, `samt.theme`, `samt.<mode>.phraseOffer`.

## Lessons

- WebKit's test build crashes on a reload after a history step back: `setup-flow.js` reopens in a new tab.
- A `//` comment inside a one-line object literal once swallowed the rest of it: keep comments off those lines.
- Amiri Quran's low marks reach ~9 px under its line box (4:114): `.ar.quran` has `padding-bottom: .35em`; reminder
  Arabic is 30 px / 2 with `text-wrap: balance`. Amiri's ﷺ is a compact seal: it sits in a `.saw` span at 1.45em.
- The repo root is an ES module package; `tests/package.json` makes the tests CommonJS.
